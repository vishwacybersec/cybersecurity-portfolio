# SOC Project 04 - Network Traffic Analysis Using Wireshark

## Project Overview

This project demonstrates practical network traffic analysis using Wireshark. A live network packet capture was created by generating normal web browsing traffic from a Kali Linux virtual machine. The captured traffic was then analyzed to understand network communications, identify protocols, examine DNS requests, inspect TCP and TLS sessions, and document the findings in a structured incident report.

This project highlights fundamental SOC Analyst skills in packet analysis, protocol investigation, and network traffic interpretation.

---

## Objectives

- Capture live network traffic using Wireshark
- Analyze DNS requests and responses
- Investigate TCP connections
- Examine TLS (HTTPS) communication
- Identify communicating endpoints
- Analyze network conversations
- Document investigation findings
- Develop practical packet analysis skills

## Investigation Summary

During the investigation, live network traffic generated through web browsing was captured and analyzed.

The investigation focused on:

- Capture Overview
- Protocol Hierarchy
- DNS Queries
- TCP Connections
- TLS Handshakes
- Endpoint Analysis
- Network Conversations

No malicious activity or indicators of compromise were identified. The captured traffic represented normal encrypted web browsing activity.

---

## Investigation Workflow

1. Capture live network traffic
2. Review Capture File Properties
3. Analyze Protocol Hierarchy
4. Investigate DNS Traffic
5. Examine TCP Sessions
6. Analyze TLS Communication
7. Review Endpoints
8. Review Conversations
9. Document Findings
10. Prepare Incident Report

---

## Key Findings

- Successfully captured live network traffic
- Observed DNS name resolution
- Verified TCP three-way handshakes
- Identified secure HTTPS communication
- Observed TLS 1.2 and TLS 1.3 sessions
- Identified communicating endpoints
- Analyzed network conversations
- No suspicious or malicious activity detected
