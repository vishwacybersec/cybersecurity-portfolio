# Project Summary

## Overview

This project demonstrates practical network traffic analysis using Wireshark. Live network traffic was captured on a Kali Linux virtual machine during normal web browsing activities and analyzed to understand network communications, protocols, and connection behavior.

---

## Objective

The primary objective was to gain hands-on experience in packet analysis by capturing and investigating network traffic. The investigation focused on identifying communication patterns, analyzing common network protocols, and documenting the findings using a structured SOC investigation methodology.

---

## Environment

- Operating System: Kali Linux
- Tool: Wireshark
- Traffic Type: Live Network Capture
- Analysis Type: Network Traffic Investigation

---

## Investigation Performed

- Captured live network traffic
- Analyzed protocol hierarchy
- Investigated DNS queries
- Examined TCP connections
- Reviewed TLS 1.2 and TLS 1.3 handshakes
- Identified communicating endpoints
- Analyzed network conversations
- Documented investigation findings

---

## Key Findings

- Successfully captured and analyzed 18,971 network packets.
- Observed legitimate DNS queries and responses.
- Verified successful TCP three-way handshakes.
- Identified encrypted HTTPS communication using TLS 1.2 and TLS 1.3.
- Analyzed endpoint communications and network conversations.
- No indicators of compromise (IOCs) or malicious activity were identified.

---

## Skills Demonstrated

- Packet Capture
- Network Traffic Analysis
- DNS Analysis
- TCP Analysis
- TLS Analysis
- Endpoint Identification
- Conversation Analysis
- Incident Documentation
- Wireshark Investigation

---

## Conclusion

This project provided practical experience in analyzing real network traffic using Wireshark. It strengthened foundational SOC Analyst skills in packet inspection, protocol analysis, and documenting investigation findings through a structured approach.
