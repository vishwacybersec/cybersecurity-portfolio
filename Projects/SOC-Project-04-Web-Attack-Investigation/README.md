# Web Attack Investigation using Apache Access Logs

## Project Overview

This project demonstrates a SOC Analyst Level 1 investigation of Apache access logs to identify suspicious web activity.

The investigation focused on analyzing web requests, identifying attack patterns, classifying suspicious activity, and documenting the findings through an incident response process.

---

## Objectives

- Analyze Apache access logs
- Identify normal and suspicious web traffic
- Detect Web Reconnaissance activity
- Detect SQL Injection attempts
- Detect Cross-Site Scripting (XSS) attempts
- Document findings and recommendations

---

## Dataset

- Apache Access Log Dataset
- Public Apache access log dataset used for cybersecurity training and analysis.
---

## Investigation Scope

This investigation focused on:

- Normal Web Requests
- Web Reconnaissance
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
